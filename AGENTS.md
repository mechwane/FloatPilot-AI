# Agent guidance — FloatPilot AI

## Scope gate
Only implement the explicitly approved phase. Phase 1 is a static synthetic prototype. Do not add backend services, authentication, persistence, APIs, server actions, forecasting calculations, AI, maps, geolocation, real financial operations or deployment without explicit approval.

## Safety and content
Use fictional agent names and locations and clearly illustrative figures. Keep the disclosure “Demo environment · Synthetic data · No funds are moved” visible on `/demo`. FloatPilot is independent and must not use or imply endorsement by any bank. Recommendations are decision support only and must never execute actions or change balances.

## Engineering
Use Node.js 24 LTS and npm, strict TypeScript, accessible semantic HTML, responsive layout, visible focus, reduced-motion support, and tests for changed behaviour. Keep controls functional and avoid dead links. Do not commit secrets.
